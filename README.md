# jsClase6
Pre-Entrega 6: Interactuando con Funciones de Orden Superior

El objetivo
El propósito de esta entrega es consolidar la interacción con los datos. Aprenderás a interactuar con tu array de objetos mediante diferentes métodos vistos en el módulo para una correcta implementación e interacción con la información.

Lo que debe incluir tu entrega:
Array de objetos Almacena tus objetos creados a partir de una Class en un array para interactuar con los mismos. Como alternativa puedes crear un array de objetos literal para simular tu base de datos.
Métodos: Mínimo tres funciones de orden superior (métodos) vistas en el módulo para interactuar con tu array de objetos.
Contexto: Los métodos que se añaden deben ser complementarios a la interacción con el simulador elegido, ejecutándose segun lo que el usuario desee hacer.

Criterios de Aceptación
Tu código debe:

Contener un array de objetos: Partiendo de los objetos instanciados en el modulo anterior o con un array de objetos literal.
Métodos de búsqueda : Mínimo dos métodos de búsqueda para interactuar con la información del array.
Métodos de transformación: Mínimo un método de transformación para modificar la información recibida desde el array.
